## 🧮 Matematiska operationer

| Operation | NFC-kod |
| --- | --- |
| Från +1 till +999 | `a001`–`a999` |
| Från −1 till −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Kvadratroten ur X | `sqrt` |
| Fakultet | `fact` |

Aritmetiken räknar från −5000 till 5000. Division och kvadratrot avrundas till närmaste heltal. Om svaret saknas (över 5000, division med 0, roten ur ett negativt tal, fakultet över 6) blinkar cellen rött och talet förblir detsamma.

## ⚙️ Inställningar

| Kommando | NFC-kod |
| --- | --- |
| Kalibrering. Utan tal ställer roboten in motorerna och gyroskopet, det tar cirka 2 minuter. Rör inte roboten den första halvminuten. Med brickan `+N` eller `−N` korrigerar roboten svängarna efter kontrollen med 32 svängar. Med ett vanligt tal fungerar brickan inte, cellen lyser rött. | `ccal` |
| Standardsteg. Anger steglängden för «Framåt» och «Bakåt». «Slumpmässig rörelse» använder samma längd (1–999 mm). Utan tal återställer brickan steget till 150 mm. | `clen` |

## 🔧 Avancerat

| Volym för kontrollpanelen och roboten (0–100, ett tal över 100 ger max) | `clvl` |

## Hur man skriver data till en NFC-tagg

Du kan skapa en egen bricka: skriv en textkod på en NFC-tagg. Du kan använda alla tal från 1 till 999, alla upprepningar och alla tal för aritmetiska operationer.

Installera appen **RFID NFC Reader** eller **NFC Tools** från Google Play Store på telefonen för att skriva koden.

Videon visar hur du skriver en NFC-tagg: [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
