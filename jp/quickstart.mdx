PrimaSTEMは、4歳から10歳以上の子ども向けの、画面を使わないプログラミング・論理・数学の学習キットです。このページでは、**装置の使い方**を簡潔に説明します。

<Note>
**端末がまだない？ ブラウザで試せます。** **[ウェブシミュレーター](https://simulator.primastem.com)** を開いてください。コントローラーとロボットの動作するコピーです。チップを置いて **▶ スタート** を押し、ロボットがプログラムを実行する様子を見てください。このガイドを読みながら試せます。
</Note>

## 1. 箱の中身

  </Card>
  <Card title="チップ" icon="square-stack">

## 2. 電源を入れる

<Steps>
  <Step title="ロボット、次にコントローラーの電源を入れる" icon="power">
    それぞれ短い音が鳴ります。緑色の電源LEDが点灯していれば、電源はONです。
  </Step>
  <Step title="白色:接続済み" icon="check">
    コントローラーの使用可能なスロットが**白色**に点灯し、ロボットの目が**白色**に点滅します。これで準備完了です。
  </Step>
  <Step title="水色:接続なし" icon="bluetooth">
    ロボットとコントローラーが水色に光ります。接続されない場合は、コントローラーの **▶ スタート** を **10秒以上**長押しします。5秒目に音が鳴りますが、ボタンを離さないでください。機器がペアリングされ、ロボットが再起動します。
  </Step>
</Steps>

**まず試してみましょう。** **前進** のチップを最初のペアに置きます。ペアのどちらのセルでも構いません。**▶ スタート** を押します。ロボットが15 cm前進して止まります。*これで、コマンド1つの最初のプログラムができました。*

## 3. プログラムの仕組み

コントローラーには**ペアスロットが2列**あります。白く光っているスロットにチップを置けば、プログラムの完成です。**▶ スタート**を押すと、ロボットが実行します。

<Frame caption="コントローラー図。A〜Fの記号は下で説明します">
  <img src="../images/book-1/control-labels.svg" alt="記号A〜F付きのコントローラー図" />
</Frame>

| 記号 | 内容 |
| :---: | --- |
| **A** | **メインプログラム**:6つのペアスロット。ロボットは左から右へ実行します |
| **B** | **▶ スタート / ストップ**:1回目に押すとプログラムが始まり、動作中に押すと止まります |
| **C** | **関数**:5つのペアスロット。「関数」チップで呼び出します |
| **D** | ペアの**1セル** |
| **E** | ペアのセルを結ぶ**実行ライン** |
| **F** | 各セルの**多色LED** |

**ペアは、つながった2つのセルです。** 上下は関係ありません。コマンドはどちらのセルに置いても構いません。もう一方のセルには、繰り返し、数値、算術のチップを置きます。2つ目のセルが空のときは、コントローラーの電源を入れてからそのコマンドが最後に受け取った数値を使います。数値をまだ設定していないときは、ロボットは歩幅15 cmで進み、90°回転します。小さな子どもにはこれで十分です。

実行中のLEDの色:

| ⚪ 白 | 🟢 緑 | 🔵 青 | 🔴 赤 |
| :---: | :---: | :---: | :---: |
| スロットが空き | ペアにコマンドがある | コマンドと数値、繰り返し、または算術 | エラー。ペアはスキップされます |

ロボットは空のスロットと赤いペアをスキップします。LEDは、ロボットがいま実行しているセルで点滅します。

## 4. グループ別のチップ

| グループ | チップの働き |
| --- | --- |
| **移動** | 前進、後退、左、右 |
| **繰り返し** | 円形の2本矢印で、内側に2〜6の点(サイコロのように、小さな子ども向け)または数字があります。コマンドとペアにすると、そのコマンドを繰り返します。 |
| **数値** | `1`から`999`まで。移動距離をミリメートル、回転角を度で指定します。 |
| **算術** | `+N` `−N` `×N` `÷N` `√` `^N`。1つのチップに演算と数値が入っています。移動または回転の保存値を変えます。結果がマイナスになると、ロボットは逆方向に進むか回転します。 |
| **関数** | 下段を副プログラムとして呼び出します。繰り返しチップと組み合わせると、下段を指定回数実行します。 |
| **デフォルトステップ** | サービスチップです。数値と組み合わせると初期歩幅を変えます。たとえば10 cmのマスには、数値100(ミリメートル)を置きます。歩幅は電源OFF後も保存されます。 |

## 5. 初期値と保存値

<Note>
**前進は150 mm(15 cm)進み、回転は90°です。**「**デフォルトステップ**」チップは初期の距離を変え、その値は電源OFF後も残ります。他のロボット用のゲームマップにも使えます。

コントローラーの電源が入っている間、各移動コマンドは**それぞれの**値を保持します:

- コマンドとペアの**数値**は、直近の保存値または初期値を置き換えます。
- **算術**チップは、その値を変えます(`+`、`−`、`×`、`÷`、`√`、`^`)。
- ペアのセルが**空**なら、直近の保存値または初期値をそのまま使います。

コントローラーの電源を切ると、保存値はリセットされます。デフォルトステップは残ります。

**早見表:**

| コントローラー上のペア | 結果 | 何が起きたか |
| --- | --- | --- |
| `前進` のみ | 150 mm(15 cm) | 初期値 |
| `前進` と `100` | 100 mm | 数値が値を置き換えた |
| `前進` と `+50` | 150 mm(前回の100に50を足した) | 算術が値を変えた |
| `左` のみ | 90° | 初期値 |
| `左` と `45` | 45° | 数値が値を置き換えた |
| `左` と `−10` | 35°(前回の45°から10°を引いた) | 算術が値を変えた |
</Note>

## 7. PrimaSTEMでの教え方

<Tip>
**コマンドチップは1つずつ、次の順序で導入してください:**

1. 前進
2. 回転
3. 繰り返し
4. 関数
5. 数値
6. 算術

子どもが前のチップをしっかり習得してから、次に進んでください。小さな子ども向けの12回レッスンの全プランは、年齢・所要時間・教材とともに[ブック1](/jp/book-1/book-1)にあります。

**グループ作業。** 1セットを **2〜3人の子ども**で使うのがおすすめです。

**マップ。** 他の教育ロボット用のマス目マップでも動きます。マスの大きさは「**デフォルトステップ**」チップと数値で設定します。たとえば100、120、150、200 mmです。

**6歩ではなく10歩にする方法。** 上段の最後(6番目)のペアに**関数 [ ]** チップを置き、マスキングテープで固定します。これでプログラムは1本のチェーンとして実行されます:上段5歩と下段5歩で**連続10歩**です。長めのプログラムが必要だけれど、関数の概念を教えるにはまだ早い小さな子どもに便利です。
</Tip>

## 8. その他の機能

<CardGroup cols={2}>
  <Card title="マーカーで描く" icon="pen-line">
    ロボットにマーカーを差し込むと、紙の上に**経路を描き**ます。単純な線から多角形、星、渦巻き、フラクタルまで描けます。
  </Card>
  <Card title="音声読み上げ" icon="volume-2">
    コントローラーは各チップを声で読み上げます。現在**21言語に対応**しており、アラビア語、フィンランド語、クロアチア語、リトアニア語も含まれます。ほかの言語もリクエストで追加します。小さな子どもや、まだ読めない子どもに役立ちます。アルファベットの文字や場所(家、学校、店、森など)もあります。
  </Card>
  <Card title="サウンドNFCシールとマップ" icon="map">
    マップにNFCタグを貼り、スマホから任意の音を書き込みます。ロボットの底面にはアンテナがあります。ロボットがタグの上で止まると、録音した音を再生します。
  </Card>
  <Card title="オープンなNFCプラットフォーム" icon="nfc">
    自分のチップを作れます。13.56 MHzのNFCタグなら何でも使えます(安価で、各種マーケットプレイスで販売されています)。そこにドキュメントのテキストコードを書き込みます。作業は無料のスマホアプリ(NFC Tools)で10秒です。
  </Card>
</CardGroup>
