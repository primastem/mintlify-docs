## NFCコードとオーディオファイルの関係

ファームウェアの各オーディオファイルにはコードがあり、コードはファイル名と同じです。たとえば、コード`cfor`のファイルは`cfor.mp3`です。
コントローラーまたはロボットがNFCチップを読み取ると、このコードを検索して対応するファイルを再生します。

一部のチップコードは **複合** で、独自のオーディオファイルがありません。
デバイスはファームウェアの容量を節約するため、既存の複数のファイルを組み合わせて再生します。

| NFCチップのコード | 再生される音声 |
|---|---|
| `r007` (リピート 7) | `xrep.mp3` + `n007.mp3` |
| `a001` (+1) | `xplu.mp3` + `n001.mp3` |
| `s005` (−5) | `xmin.mp3` + `n005.mp3` |
| `m002` (×2) | `xmul.mp3` + `n002.mp3` |
| `d003` (÷3) | `xdiv.mp3` + `n003.mp3` |
| `e002` (X²) | `xpow.mp3` + `n002.mp3` |

NFCチップのコード一覧とキットの内容は[チップ](/jp/nfc)にあります。
