PrimaSTEMの土台には[LOGO](https://ja.wikipedia.org/wiki/LOGO)の考え方があります。この子ども向けの言語は、シーモア・パパートと同僚たちが1967年に作りました。LOGOでは、子どもがコマンドを入力すると、画面上のタートルが絵を描きます。PrimaSTEMでは、子どもがコントローラーにチップを置くと、マーカー付きの木製ロボットが紙に絵を描きます。キーボードも画面も文字も使いません。

このページは、LOGOやScratchを知っている先生と、チップが実際に何をしているのかを知りたいすべての方に向けたものです。

## コントローラー上の概念

| 概念 | PrimaSTEMのコントローラーでは | LOGOでは |
|---|---|---|
| 順次実行 | チップは上段を左から右へ順に実行されます。実行中のペアのLEDが点滅し、そのあと消えます | コマンドを1つずつ順に実行 |
| コマンド | 前進、後退、左、右、一時停止、ランダム移動 | `forward`、`back`、`left`、`right`、`wait` |
| パラメーター | 同じペアに置いた数値チップ:前進 + 200 | `forward 200` |
| 初期値 | 数値なしの前進 = 150 mm、数値なしの左/右 = 90° | |
| ループ | ペアに置いた繰り返しチップ:前進 + 繰り返し4 | `repeat 4 [forward 150]` |
| 手続き | 下段(5ペア)が関数です。「関数」チップで呼び出します | `to shape ... end`、そのあと `shape` |
| ループ内の手続き | 「関数」チップと繰り返しチップを同じペアに置きます:関数 + 繰り返し5 | `repeat 5 [shape]` |
| 手続きに値を渡す | 前進100は100 mm進み、100を覚えます。続けて、数値なしの前進が入った関数を呼ぶと、そこでも100進みます。次の呼び出しの前に前進を変えると、同じ関数が別の大きさの図形を描きます | `shape 100`、`shape 50` に近い |
| 再帰 | 下段に置いた「関数」チップ:もう一度 ▶ スタート を押すまで、関数が自分自身を呼び続けます | 自分自身を呼ぶ手続き |
| 変数 | 各コマンドは自分の直近の値を覚えています。前進、後退、左、右、一時停止は5つの独立した変数です。数値なしの前進は、前回の前進と同じ距離を進みます | `make "step 200`、そのあと `forward :step` |
| 変数の算術 | 前進 + 「+30」:覚えた値に30を足して進みます | `make "step :step + 30 forward :step` |
| 演算 | 覚えた値に + − × ÷ √ ^ を使います。範囲は−5000から5000、整数のみ | `sum`、`difference`、`product`、`quotient`、`sqrt`、`power` |
| 負の値 | 結果が負になると動きが逆になります。前進−50は50 mm後ろへ進み、左−30は右へ30°回ります | `forward -50` |
| ランダム | サイコロの繰り返しチップ(1〜6回)と「ランダム移動」チップ | `random 6` |
| ペン | ロボットの中心に差し込むマーカー | `pendown` |
| デバッグ | ロボットを見て、間違ったチップを見つけ、取り替えます | 行を直す |

覚えた値はコマンドごとに別々です。前進を変えても、左は変わりません。コントローラーの電源を切ると、すべての値が初期値に戻ります:150 mm、90°、一時停止は1秒です。初期歩幅は、サービスチップ「デフォルトステップ長の設定」でずっと変えておけます([本体と設定](usermanual)を参照)。

計算するのは子どもです。ロボットはプログラムを正確に実行します。

## 例:同じプログラムをコントローラーとLOGOで

コントローラー:上段 関数 × 4。下段:前進300、右。

### 六角形(割り算で角度を出す)

コントローラー:上段 右360、右 ÷6、関数 × 6。下段:前進200、右。

```
make "angle 360 / 6
repeat 6 [forward 200 right :angle]
```

右360は1回転して、360を覚えます。右 ÷6は覚えた値を割り、60°回ります。関数の中では、数値なしの右がまた60°を使います。最初の2回の回転は、描き始める前のロボットの向きを変えるだけです。図形は六角形のままです。

## PrimaSTEMとLOGOの違い

PrimaSTEMはLOGOのタートルグラフィックスの基本をカバーしています。いくつかの点は意図的に違う作りになっています:

- **1つのペアに1つのコマンドと1つの値。** ペアのセルには、コマンドと、値を最大1つ置きます。値は数値、繰り返し、演算のどれかです。だから4歳の子どもでもプログラムを読めます。
- **条件(`if`)はありません。** プログラムは毎回同じように実行されます。ランダムになるのはサイコロとランダム移動だけです。
- **関数には名前付きのパラメーターがありません。** 繰り返しと一緒に呼び出し、呼び出しの前に設定した値を使います(上の表を参照)。
- **プログラムの長さ:** メインの段に6ペア、関数に5ペアです。
- **マーカーは手で差し込みます。** 子どもがロボットに描かせたいときに差します。

子どもがコントローラーを卒業したら、同じロボットを[Scratch](https://scratch.primastem.com)で使えます。
