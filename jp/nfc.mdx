## 🧮 数学演算

| 演算 | NFC コード |
| --- | --- |
| +1 〜 +999 | `a001`–`a999` |
| −1 〜 −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| X の平方根 | `sqrt` |
| 階乗 | `fact` |

演算は−5000から5000までの範囲で計算します。割り算と平方根は最も近い整数に丸めます。答えが出ない場合（5000超、0での割り算、負の数の平方根、6より大きい階乗）は、セルが赤く点滅し、数値は前のままです。

## ⚙️ 設定

| コマンド | NFC コード |
| --- | --- |
| キャリブレーション。数値なしでは、ロボットがモーターとジャイロスコープを調整します。約2分かかります。最初の30秒はロボットに触らないでください。`+N` または `−N` のチップと組み合わせると、ロボットは32回の回転で確認したあとに回転を補正します。普通の数値ではチップは動作せず、セルが赤く点灯します。 | `ccal` |
| デフォルトステップ。「前進」と「後退」の1歩の長さを設定します。「ランダム移動」も同じ長さを使います（1〜999 mm）。数値なしでは150 mmに戻ります。 | `clen` |

## 🔧 上級

| コマンド | NFC コード |
| --- | --- |
| サウンド（一覧は [オーディオファイル参照](/jp/sounds_reference)） | `xNNN` |
| ロボットのフレーズ。`csou` と数値Nを置くと、ロボットが[オーディオファイル](/jp/sounds_reference#-ロボットのフレーズ・反応・サービスメッセージ-x001–x019)のフレーズ xN を話します。 | `csou` |
| コントローラーとロボットの音量（0〜100。100を超える数値は最大になります） | `clvl` |

## NFC タグへのデータの書き込み方

自分のチップを作れます。NFC タグにテキストコードを書き込んでください。1〜999 の任意の数値、任意の繰り返し、算術演算用の任意の数値を使えます。

書き込むには、Google Play ストアからスマートフォンに **RFID NFC Reader** または **NFC Tools** アプリをインストールします。

NFC タグの書き込み方は動画で紹介しています：[youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
