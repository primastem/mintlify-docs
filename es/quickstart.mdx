## Configuración de desarrollo

Aprende cómo actualizar tu documentación localmente y publicarla públicamente.

### Edición y vista previa

<AccordionGroup>
  <Accordion icon="github" title="Clona tu documentación localmente">
    Durante el proceso de incorporación, creamos un repositorio en tu Github con
    el contenido de tu documentación. Puedes encontrar este repositorio en
    tu [panel de control](https://dashboard.mintlify.com). Para clonar el repositorio
    localmente, sigue estas
    [instrucciones](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)
    en tu terminal.
  </Accordion>
  <Accordion icon="rectangle-terminal" title="Vista previa de cambios">
    La vista previa ayuda a asegurar que tus cambios se vean como se pretende. Hemos creado
    una interfaz de línea de comandos para mostrar estos cambios localmente.
    1. Instala
    [Mintlify CLI](https://www.npmjs.com/package/mintlify) para obtener una vista previa local
    de los cambios de documentación con este comando: ``` npm i -g mintlify ```
    2. Ejecuta el siguiente comando en la raíz de tu documentación (donde
    se encuentra `docs.json`): ``` mintlify dev ```
    <Note>
      Si actualmente estás usando un archivo de configuración heredado ```mint.json```, actualiza Mintlify CLI:


      ```npm i -g mintlify@latest```
      Y ejecuta el nuevo comando de actualización en el repositorio de tu documentación:

      ```mintlify upgrade```
      Ahora debes usar el nuevo archivo de configuración ```docs.json```. Siéntete libre de eliminar el archivo ```mint.json``` de tu repositorio.
    </Note>
  </Accordion>
</AccordionGroup>

### Implementación de tus cambios

<AccordionGroup>

<Accordion icon="message-bot" title="Instala nuestra aplicación de Github">
  Nuestra aplicación de Github implementa automáticamente tus cambios en el sitio de documentación,
  por lo que no necesitas gestionar las implementaciones tú mismo. El enlace de instalación se encuentra en
  tu [panel de control](https://dashboard.mintlify.com). Una vez que el bot esté instalado correctamente,
  debería aparecer una marca de verificación junto al hash de confirmación del repositorio.
</Accordion>
<Accordion icon="rocket" title="Envía tus cambios">
  [Confirma y envía tus cambios a
  Git](https://docs.github.com/en/get-started/using-git/pushing-commits-to-a-remote-repository#about-git-push)
  para actualizar tu sitio de documentación. Si has enviado cambios y no ves
  que la aplicación de Github haya implementado tus cambios correctamente, también puedes
  actualizar manualmente tu documentación a través de nuestro [panel de control](https://dashboard.mintlify.com).
</Accordion>

</AccordionGroup>
