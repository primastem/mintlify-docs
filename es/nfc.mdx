## 🧮 Operaciones matemáticas

| Operación | NFC Code |
| --- | --- |
| +1 to +999 | `a001`–`a999` |
| −1 to −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Raíz cuadrada de X | `sqrt` |
| Factorial | `fact` |

La aritmética cuenta hasta 5000 en ambos sentidos, la división es sin decimales. Si no hay respuesta (más de 5000, división entre 0, raíz de un número negativo, factorial mayor que 6), la celda parpadea en rojo y el número no cambia.

## ⚙️ Configuración

| Comando | NFC Code |
| --- | --- |
| Calibración. Sin número: el robot ajusta los motores y el giroscopio, unos 2 minutos, no tocarlo durante el primer medio minuto. Con una ficha `+N` o `−N`: corrección de los giros después de la prueba de 16 giros. No funciona con un número simple (celda roja) | `ccal` |
| Establecer longitud de paso predeterminada (1–999 mm; sin número vuelve a 150 mm) | `clen` |

## 🔧 Avanzado

| Comando | NFC Code |
| --- | --- |
| Muestra de audio (ver [Archivos de audio](/es/sounds_reference)) | `xNNN` |
| Sonido: el robot reproduce el sonido número N (`csou` + número N) | `csou` |
| Volumen del mando y del robot: 0–100, más de 100 = máximo | `clvl` |

## Cómo escribir datos en una etiqueta NFC

Puedes crear tu propia ficha — simplemente escribe un código de texto en una etiqueta NFC. Puedes usar cualquier número (del 0 al 999), cualquier repetición y cualquier número para operaciones aritméticas.

Para escribir datos de texto en una etiqueta NFC, abre Google Play Store e instala la aplicación **RFID NFC Reader** o **NFC Tools** en tu teléfono.

Las instrucciones para escribir una etiqueta NFC están aquí — [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
