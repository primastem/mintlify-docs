## 🧮 Operaciones matemáticas

| Operación | Código NFC |
| --- | --- |
| De +1 a +999 | `a001`–`a999` |
| De −1 a −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Raíz cuadrada de X | `sqrt` |
| Factorial | `fact` |

La aritmética cuenta de −5000 a 5000. La división y la raíz se redondean al entero más cercano. Si no hay respuesta (más de 5000, división entre 0, raíz de un número negativo, factorial mayor que 6), la celda parpadea en rojo y el número no cambia.

## ⚙️ Configuración

| Comando | Código NFC |
| --- | --- |
| Calibración. Sin número, el robot ajusta los motores y el giroscopio. Esto tarda unos 2 minutos. No toque el robot durante el primer medio minuto. Con una ficha `+N` o `−N`, el robot corrige los giros después de la prueba de 32 giros. Con un número simple, la ficha no funciona y la celda se pone roja. | `ccal` |
| Paso predeterminado. Fija la longitud de paso para «Adelante» y «Atrás». «Movimiento aleatorio» también la usa (1–999 mm). Sin número, la ficha devuelve el paso a 150 mm. | `clen` |

| Volumen del tablero y del robot (0–100, un número mayor que 100 da el máximo) | `clvl` |

## Cómo escribir datos en una etiqueta NFC

Puede crear su propia ficha: escriba un código de texto en una etiqueta NFC. Sirve cualquier número del 1 al 999, cualquier repetición y cualquier número para operaciones aritméticas.

Para grabar la etiqueta, instale en su teléfono la aplicación **RFID NFC Reader** o **NFC Tools** desde Google Play Store.

El vídeo muestra cómo escribir una etiqueta NFC: [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
