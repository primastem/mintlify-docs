## Cómo se relacionan los códigos NFC y los archivos de audio

Cada archivo de audio del firmware tiene un código que coincide con su nombre de archivo. Por ejemplo, al código `cfor` le corresponde el archivo `cfor.mp3`.
Cuando el tablero o el robot lee una ficha NFC, busca este código y reproduce el archivo correspondiente.

Algunos códigos de fichas son **compuestos**: no tienen archivo de audio propio.
El dispositivo los forma con varios archivos existentes para ahorrar espacio de firmware.

| Código de la ficha NFC | Se reproduce como |
|---|---|
| `r007` (Repetir 7) | `xrep.mp3` + `n007.mp3` |
| `a001` (+1) | `xplu.mp3` + `n001.mp3` |
| `s005` (−5) | `xmin.mp3` + `n005.mp3` |
| `m002` (×2) | `xmul.mp3` + `n002.mp3` |
| `d003` (÷3) | `xdiv.mp3` + `n003.mp3` |
| `e002` (X²) | `xpow.mp3` + `n002.mp3` |

La lista completa de códigos de fichas NFC y el contenido del kit está en [Fichas de comando](/es/nfc).
