## 🧮 Math operations

| Operation | NFC code |
| --- | --- |
| +1 to +999 | `a001`–`a999` |
| −1 to −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Square Root of X | `sqrt` |
| Factorial | `fact` |

Arithmetic works in the range from −5000 to 5000. Division and square root round to the nearest whole number. If there is no answer (above 5000, division by 0, root of a negative number, factorial above 6), the cell blinks red and the number stays the same.

## ⚙️ Settings

| Command | NFC code |
| --- | --- |
| Calibration. Without a number, the robot tunes its motors and gyroscope. This takes about 2 minutes. Do not touch the robot for the first half minute. With a `+N` or `−N` token, the robot corrects its turns after the 32-turn check. With a plain number, the token does not work and the cell turns red. | `ccal` |
| Default Step. Sets the step length for “Forward” and “Backward”. “Random Movement” uses it too (1–999 mm). Without a number, the token returns the step to 150 mm. | `clen` |

## 🔧 Advanced

| Command | NFC code |
| --- | --- |
| Sound (see [Audio files reference](/en/sounds_reference)) | `xNNN` |
| Robot Phrase. Place `csou` with a number N, and the robot says phrase xN from the [sounds table](/en/sounds_reference#-robot-phrases-reactions-&-service-x001–x019) | `csou` |
| Volume of the control board and robot (0–100, a number above 100 gives the maximum) | `clvl` |

## How to write data to an NFC tag

You can make your own token: write a text code to an NFC tag. Any numbers from 1 to 999, any repeats and any numbers for arithmetic operations work.

To write a tag, install the **RFID NFC Reader** or **NFC Tools** app on your phone from the Google Play Store.

This video shows how to write an NFC tag: [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
