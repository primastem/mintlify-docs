## 🧮 Math Operations

| Operation | NFC Code |
| --- | --- |
| +1 to +999 | `a001`–`a999` |
| −1 to −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Square Root of X | `sqrt` |
| Factorial | `fact` |

Arithmetic counts up to 5000 in both directions, division drops fractions. If there is no answer (above 5000, division by 0, root of a negative number, factorial above 6), the cell blinks red and the number stays the same.

## ⚙️ Settings

| Command | NFC Code |
| --- | --- |
| Calibration (without a number: the robot tunes its motors and gyroscope, about 2 minutes, do not touch it for the first half minute; with a `+N` or `−N` chip: turn correction after the 16-turn check; does not work with a plain number, the cell turns red) | `ccal` |
| Set Default Step Length for map (1–999 mm; without a number returns to 150 mm) | `clen` |

## 🔧 Advanced

| Command | NFC Code |
| --- | --- |
| Audio Sample (see [Audio Files Reference](/en/sounds_reference)) | `xNNN` |
| Sound Sample (the robot plays sound number N: `csou` + number N) | `csou` |
| Volume Level (remote and robot: 0–100, above 100 = maximum) | `clvl` |

## How to Write Data to an NFC Tag

You can create your own token — simply write a text code to an NFC tag. You can use any numbers (from 0 to 999), any repetitions, and any numbers for arithmetic operations.

To write text data to an NFC tag, open the Google Play Store and install the **RFID NFC Reader** or **NFC Tools** app on your phone.

Instructions for writing an NFC tag are here — [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
