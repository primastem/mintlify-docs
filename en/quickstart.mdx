PrimaSTEM teaches children ages 4–10+ programming, logic, and mathematics without a screen. This page briefly explains **how the device works**.

<Note>
**No device yet? Try it in your browser.** Open the **[Web simulator](https://simulator.primastem.com)**. It is a working copy of the control board and robot. Place tokens, press **▶ Start**, and watch the robot run the program. You can do this while you read this guide.
</Note>

## 2. Power on

<Steps>
  <Step title="Switch on the robot, then the control board" icon="power">
    Each device plays a short sound. The green power indicator means that the device is on.
  </Step>
  <Step title="White: connected" icon="check">
    Free cells on the control board glow **white**, the robot's eyes blink **white**. You're ready.
  </Step>
  <Step title="Light blue: no connection" icon="bluetooth">
    The robot and the control board glow light blue. If the connection does not come up, hold **▶ Start** on the control board for **more than 10 seconds**. You will hear a beep at the 5th second. Do not release the button. The devices will pair, and the robot will restart.
  </Step>
</Steps>

**Try this first.** Place a **Forward** token in the first pair, in either of its two cells. Press **▶ Start**. The robot moves 15 cm forward and stops. *You wrote your first program, with one command.*

## 3. How a program works

The control board has **two rows of paired cells**. Place tokens in the cells that glow white, and your program is ready. Press **▶ Start**, and the robot runs it.

<Frame caption="Control board layout. Labels A–F are explained below">
  <img src="../images/book-1/control-labels.svg" alt="Control board diagram with labels A through F" />
</Frame>

| Label | What it is |
| :---: | --- |
| **A** | **Main program**: 6 pairs of cells, the robot runs them from left to right |
| **B** | **▶ Start / Stop**: the first press starts the program, a press during movement stops it |
| **C** | **Function**: 5 pairs of cells, the Function token calls them |
| **D** | One **cell** of a pair |
| **E** | **Execution line** that links two cells into a pair |
| **F** | **Multi-colour indicator** on each cell |

**A pair is two linked cells.** Top and bottom do not matter. Put the command in either cell of the pair, and put the repeat, number, or arithmetic token in the other. If the second cell is empty, the command uses the last number it received since the control board was switched on. Until you set a number, the robot makes a 15 cm step and a 90° turn. This is enough for young children.

Indicator colours during the program:

| ⚪ White | 🟢 Green | 🔵 Blue | 🔴 Red |
| :---: | :---: | :---: | :---: |
| Cell is free | Pair has a command | Command with a number, repeat, or arithmetic | Error, the pair is skipped |

The robot skips empty cells and red pairs. The indicator flashes on the cell that the robot runs right now.

## 4. Tokens by group

| Group | What the tokens do |
| --- | --- |
| **Movement** | Forward, Backward, Left, Right |
| **Repeat** | Two arrows in a loop, with dots from 2 to 6 inside (like a die, for young children) or numerals. In a pair with a command, they repeat it. |
| **Numbers** | From `1` to `999`. They set the distance in millimetres or the turn angle in degrees. |
| **Arithmetic** | `+N` `−N` `×N` `÷N` `√` `^N`. One token holds an operation and a number. It changes the saved value of movement or turn. If the result is negative, the robot moves or turns in the opposite direction. |
| **Function** | Calls the bottom row as a subroutine. With a repeat token, the bottom row runs that number of times. |
| **Default Step** | Service token. With a number, it changes the default step. For example, for 10 cm cells, put the number 100 (in millimetres). The step is saved after power-off. |

## 5. Defaults & saved value

<Note>
**Forward moves 150 mm (15 cm), a turn is 90°.** The **Default Step** token changes the default distance, and it stays after power-off. This way the control board fits maps from any robot.

While the control board is on, each movement command keeps its **own** value:

- **a number** in the pair with the command replaces the last saved value or the default value;
- **an arithmetic** token changes it (`+`, `−`, `×`, `÷`, `√`, `^`);
- an **empty** cell in the pair keeps the last saved value or the default value.

When you switch off the control board, the saved values reset. The default step stays.

**Quick reference:**

| Pair on the control board | Result | What happened |
| --- | --- | --- |
| `Forward` without a number | 150 mm (15 cm) | default value |
| `Forward` and `100` | 100 mm | the number replaced the value |
| `Forward` and `+50` | 150 mm (was 100, added 50) | arithmetic changed the value |
| `Left` without a number | 90° | default value |
| `Left` and `45` | 45° | the number replaced the value |
| `Left` and `−10` | 35° (was 45°, subtracted 10°) | arithmetic changed the value |
</Note>

## 7. How to teach with PrimaSTEM

<Tip>
**Introduce command tokens one at a time, in this order:**

1. Forward
2. Turns
3. Repeat
4. Function
5. Numbers
6. Arithmetic

Move to the next token when the child has confidently mastered the previous one. The full 12-lesson plan for young children, with age, duration, and materials, is in [Book 1](/en/book-1/book-1).

**Group work.** We recommend one kit per **2–3 children**.

**Maps.** Any map made for any other educational robot will work. The **Default Step** token with a number sets the cell size, for example 100, 120, 150, or 200 mm.

**How to get 10 steps instead of 6.** Place the **Function [ ]** token in the last (6th) pair of the top row and secure it with masking tape. Now the program runs as one chain: 5 steps on top and 5 on the bottom, **10 steps in a row**. This is useful for young children who need a longer program, but are not yet ready for the function concept.
</Tip>

## 8. More features

<CardGroup cols={2}>
  <Card title="Marker and drawing" icon="pen-line">
    Insert a marker in the robot, and it will **draw** its path on paper. You get simple lines, polygons, stars, spirals, and fractals.
  </Card>
  <Card title="Voice feedback" icon="volume-2">
    The control board says each token aloud. The voice works in **21 languages**, including Arabic, Finnish, Croatian, and Lithuanian. We will add another language on request. The voice helps young children who cannot read yet. It includes alphabet letters and places: Home, School, Shop, Forest, and others.
  </Card>
  <Card title="NFC sound stickers and maps" icon="map">
    Stick NFC tags on your map and write any available sound to them from your phone. The robot has an antenna underneath. When the robot stops on a tag, it plays the recorded sound.
  </Card>
  <Card title="Open NFC platform" icon="nfc">
    Write your own tokens. You need any 13.56 MHz NFC tag (cheap tags of all kinds are sold on every marketplace) and a text code from our documentation. Writing takes 10 seconds in the free NFC Tools app on your phone.
  </Card>
</CardGroup>
