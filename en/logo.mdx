PrimaSTEM is built on the idea of [LOGO](https://en.wikipedia.org/wiki/Logo_(programming_language)). Seymour Papert and his colleagues created this language for children in 1967. In LOGO a child types commands and a turtle draws on the screen. In PrimaSTEM the child places tokens on the board, and a wooden robot with a marker draws on paper. No keyboard, no screen, no text.

This page is for teachers who know LOGO or Scratch, and for anyone who wants to see what the tokens really do.

## Concepts on the board

| Concept | On the PrimaSTEM board | In LOGO |
|---|---|---|
| Sequence | Tokens run left to right along the top row. The LED of the running pair blinks, then goes dark | one command after another |
| Command | Forward, Back, Left, Right, Pause, Random Movement | `forward`, `back`, `left`, `right`, `wait` |
| Parameter | A number token in the same pair: Forward + 200 | `forward 200` |
| Default value | Forward with no number = 150 mm, Left/Right with no number = 90° | |
| Loop | A repeat token in the pair: Forward + repeat 4 | `repeat 4 [forward 150]` |
| Procedure | The bottom row (5 pairs) is the Function. The Function token calls it | `to shape ... end`, then `shape` |
| Procedure in a loop | The Function token and a repeat token in one pair: Function + repeat 5 | `repeat 5 [shape]` |
| Giving a procedure a value | Forward 100 moves 100 mm and saves 100. If you call a Function next that has Forward with no number, it also moves 100. Change Forward before the next call, and the same Function draws the shape in a different size | similar to `shape 100`, `shape 50` |
| Recursion | A Function token inside the bottom row: the function calls itself until you press ▶ Start again | a procedure that calls itself |
| Variables | Each command remembers its own last value: Forward, Back, Left, Right and Pause are five independent variables. Forward with no number moves as far as the last Forward | `make "step 200`, then `forward :step` |
| Arithmetic on a variable | Forward + "+30": add 30 to the saved value, then move | `make "step :step + 30 forward :step` |
| Operations | + − × ÷ √ ^ on the saved value, from −5000 to 5000, whole numbers | `sum`, `difference`, `product`, `quotient`, `sqrt`, `power` |
| Negative values | A negative result reverses the move: Forward −50 goes back 50 mm, Left −30 turns right 30° | `forward -50` |
| Randomness | The repeat token with the dice (1 to 6 times) and the Random Movement token | `random 6` |
| Pen | A marker in the centre of the robot | `pendown` |
| Debugging | Watch the robot, find the wrong token, swap it | edit the line |

Each command has its own saved value: changing Forward does not change Left. When the board is switched off, all values go back to the defaults: 150 mm, 90°, 1 s for Pause. To change the default step for good, use the "Set Default Step Length" service token (see [Device & Setup](usermanual)).

The child does the calculating. The robot carries out the program exactly.

### Square spiral (variable and arithmetic)

Board: top row Forward 30, Function × 20. Bottom row: Right, Forward +30.

```
make "side 30
forward :side
repeat 20 [
  right 90
  make "side :side + 30
  forward :side
]
```

### Hexagon (an angle from division)

Board: top row Right 360, Right ÷6, Function × 6. Bottom row: Forward 200, Right.

make "angle 360 / 6

Right 360 makes one full turn and saves 360. Right ÷6 divides the saved value and turns 60°. In the function, Right with no number takes 60° again. The two turns at the start only change where the robot faces before it draws; the shape stays a hexagon.

The board divides in whole numbers and drops the remainder. For the shape to close, divide 360 by a number that leaves no remainder: 3, 4, 5, 6, 8, 9, 10, 12. For example, 360 ÷ 7 gives 51°, and the heptagon misses closing by 3°.

## Where PrimaSTEM differs from LOGO

PrimaSTEM covers the core of LOGO turtle graphics. A few things work differently, by design:

- **One pair, one command and one value.** A pair of cells holds a command and at most one value: a number, a repeat or an operation. This keeps a program readable even for a four-year-old.
- **No conditions (`if`).** The program runs the same way every time. Only the dice and Random Movement add chance.
- **The Function has no named parameters.** You call it with a repeat, and it uses the values set before the call (see the table above).
- **Program length:** 6 pairs in the main row, 5 in the Function.
- **You put the marker in by hand** when the child wants the robot to draw.

When a child outgrows the board, the same robot works with [Scratch](https://scratch.primastem.com).
