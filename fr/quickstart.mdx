## Configuration du développement

Découvrez comment mettre à jour votre documentation localement et la publier publiquement.

### Modification et aperçu

<AccordionGroup>
  <Accordion icon="github" title="Clonez votre documentation localement">
    Lors du processus d'intégration, nous avons créé un dépôt sur votre Github avec
    le contenu de votre documentation. Vous pouvez trouver ce dépôt sur
    le [tableau de bord](https://dashboard.mintlify.com). Pour cloner le dépôt
    localement, suivez ces
    [instructions](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)
    dans votre terminal.
  </Accordion>
  <Accordion icon="rectangle-terminal" title="Aperçu des modifications">
    L'aperçu vous aide à vérifier que vos modifications apparaissent comme prévu. Nous avons créé
    une interface en ligne de commande pour afficher ces modifications localement.
    1. Installez
    [Mintlify CLI](https://www.npmjs.com/package/mintlify) pour afficher localement
    les modifications de documentation avec cette commande : ``` npm i -g mintlify ```
    2. Exécutez la commande suivante à la racine de votre documentation (là où
    se trouve `docs.json`) : ``` mintlify dev ```
    <Note>
      Si vous utilisez actuellement un fichier de configuration obsolète ```mint.json```, veuillez mettre à jour Mintlify CLI :


      ```npm i -g mintlify@latest```
      Puis exécutez la nouvelle commande de mise à niveau dans le dépôt de votre documentation :

      ```mintlify upgrade```
      Vous devez maintenant utiliser le nouveau fichier de configuration ```docs.json```. N'hésitez pas à supprimer le fichier ```mint.json``` de votre dépôt.
    </Note>
  </Accordion>
</AccordionGroup>

### Déploiement de vos modifications

<AccordionGroup>

<Accordion icon="message-bot" title="Installez notre application Github">
  Notre application Github déploie automatiquement vos modifications sur le site de documentation,
  vous n'avez donc pas à gérer les déploiements vous-même. Le lien d'installation se trouve sur
  votre [tableau de bord](https://dashboard.mintlify.com). Une fois le bot installé avec succès,
  une coche devrait apparaître à côté du hachage de commit du dépôt.
</Accordion>
<Accordion icon="rocket" title="Poussez vos modifications">
  [Committez et poussez vos modifications vers
  Git](https://docs.github.com/en/get-started/using-git/pushing-commits-to-a-remote-repository#about-git-push)
  pour mettre à jour votre site de documentation. Si vous avez poussé des modifications et ne voyez pas
  que l'application Github a déployé vos modifications avec succès, vous pouvez également
  mettre à jour manuellement votre documentation via notre [tableau de bord](https://dashboard.mintlify.com).
</Accordion>

</AccordionGroup>
