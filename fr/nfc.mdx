## 🧭 Mouvement

| Commande | NFC Code |
| --- | --- |
| Avancer | `cfor` |
| Gauche | `clef` |
| Droite | `crig` |
| Reculer | `cbac` |
| Mouvement aléatoire | `crnd` |

## 🔁 Répétition & Contrôle

| Commande | NFC Code |
| --- | --- |
| Répéter 2–999 | `r002`–`r999` |
| Répéter Nombre aléatoire (de 1 à 6) | `rrnd` |
| Fonction | `cfun` |
| Pause | `cwat` |

## 🔢 Nombres

| Valeur | NFC Code |
| --- | --- |
| Nombres 1–999 | `n001`–`n999` |

## 🧮 Opérations mathématiques

| Opération | NFC Code |
| --- | --- |
| +1 to +999 | `a001`–`a999` |
| −1 to −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Racine carrée de X | `sqrt` |
| Factorielle | `fact` |

## ⚙️ Paramètres

| Commande | NFC Code |
| --- | --- |
| Calibration de distance | `ccal` |
| Définir la longueur de pas par défaut | `clen` |

## 🔧 Avancé

| Commande | NFC Code |
| --- | --- |
| Échantillon audio (voir [Fichiers audio](/fr/sounds_reference)) | `xNNN` |
| Échantillon sonore du panneau | `csou` |
| Niveau de volume | `clvl` |

## Comment écrire des données sur une étiquette NFC

Vous pouvez créer votre propre jeton — il suffit d'écrire un code texte sur une étiquette NFC. Vous pouvez utiliser n'importe quels nombres (de 0 à 999), n'importe quelles répétitions et n'importe quels nombres pour les opérations arithmétiques.

Pour écrire des données texte sur une étiquette NFC, ouvrez le Google Play Store et installez l'application **RFID NFC Reader** ou **NFC Tools** sur votre téléphone.

Les instructions pour écrire une étiquette NFC se trouvent ici — [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
