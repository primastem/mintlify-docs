## 🧮 Opérations mathématiques

| Opération | NFC Code |
| --- | --- |
| +1 to +999 | `a001`–`a999` |
| −1 to −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Racine carrée de X | `sqrt` |
| Factorielle | `fact` |

L'arithmétique compte jusqu'à 5000 dans les deux sens, la division se fait sans décimales. S'il n'y a pas de réponse (plus de 5000, division par 0, racine d'un nombre négatif, factorielle de plus de 6), la cellule clignote en rouge et le nombre reste le même.

## ⚙️ Paramètres

| Commande | NFC Code |
| --- | --- |
| Calibration. Sans nombre : le robot règle ses moteurs et son gyroscope, environ 2 minutes, ne pas le toucher pendant la première demi-minute. Avec un jeton `+N` ou `−N` : correction des rotations après le test de 16 rotations. Ne fonctionne pas avec un nombre simple (cellule rouge) | `ccal` |
| Définir la longueur de pas par défaut (1–999 mm ; sans nombre, revient à 150 mm) | `clen` |

## Comment écrire des données sur une étiquette NFC

Vous pouvez créer votre propre jeton — il suffit d'écrire un code texte sur une étiquette NFC. Vous pouvez utiliser n'importe quels nombres (de 0 à 999), n'importe quelles répétitions et n'importe quels nombres pour les opérations arithmétiques.

Pour écrire des données texte sur une étiquette NFC, ouvrez le Google Play Store et installez l'application **RFID NFC Reader** ou **NFC Tools** sur votre téléphone.

Les instructions pour écrire une étiquette NFC se trouvent ici — [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
