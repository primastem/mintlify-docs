## 🧮 Opérations mathématiques

| Opération | Code NFC |
| --- | --- |
| De +1 à +999 | `a001`–`a999` |
| De −1 à −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Racine carrée de X | `sqrt` |
| Factorielle | `fact` |

L'arithmétique compte de −5000 à 5000. La division et la racine sont arrondies à l'entier le plus proche. S'il n'y a pas de réponse (plus de 5000, division par 0, racine d'un nombre négatif, factorielle de plus de 6), la cellule clignote en rouge et le nombre reste le même.

## ⚙️ Paramètres

| Commande | Code NFC |
| --- | --- |
| Calibration. Sans nombre, le robot règle ses moteurs et son gyroscope. Cela prend environ 2 minutes. Ne touchez pas le robot pendant la première demi-minute. Avec un jeton `+N` ou `−N`, le robot corrige ses rotations après le test de 32 rotations. Avec un nombre simple, le jeton ne fonctionne pas et la cellule devient rouge. | `ccal` |
| Pas par défaut. Fixe la longueur du pas pour « Avancer » et « Reculer ». « Mouvement aléatoire » l'utilise aussi (1–999 mm). Sans nombre, le jeton remet le pas à 150 mm. | `clen` |

## Comment écrire des données sur une étiquette NFC

Vous pouvez créer votre propre jeton : écrivez un code texte sur une étiquette NFC. Tous les nombres de 1 à 999, toutes les répétitions et tous les nombres pour les opérations arithmétiques conviennent.

Pour écrire l'étiquette, installez sur votre téléphone l'application **RFID NFC Reader** ou **NFC Tools** depuis le Google Play Store.
