## Comment les codes NFC et les fichiers audio sont liés

Chaque fichier audio du firmware a un code qui correspond à son nom de fichier. Par exemple, le code `cfor` correspond au fichier `cfor.mp3`.
Lorsque le tableau de contrôle ou le robot lit un jeton NFC, il recherche ce code et joue le fichier correspondant.

Certains codes de jetons sont **composites** : ils n'ont pas de fichier audio propre.
L'appareil les compose à partir de plusieurs fichiers existants pour économiser l'espace du firmware.

| Code du jeton NFC | Lu comme |
|---|---|
| `r007` (Répéter 7) | `xrep.mp3` + `n007.mp3` |
| `a001` (+1) | `xplu.mp3` + `n001.mp3` |
| `s005` (−5) | `xmin.mp3` + `n005.mp3` |
| `m002` (×2) | `xmul.mp3` + `n002.mp3` |
| `d003` (÷3) | `xdiv.mp3` + `n003.mp3` |
| `e002` (X²) | `xpow.mp3` + `n002.mp3` |

La liste complète des codes des jetons NFC et le contenu du kit se trouvent dans [Jetons de commande](/fr/nfc).
