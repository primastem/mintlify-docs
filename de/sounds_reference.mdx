## Wie NFC-Codes und Audiodateien zusammenhängen

Jede Audiodatei in der Firmware hat einen Code, der ihrem Dateinamen entspricht (z. B. `cfor` → `cfor.mp3`).
Wenn die Fernbedienung oder der Roboter einen NFC-Chip liest, sucht das Gerät diesen Code und spielt die entsprechende Datei ab.

Einige NFC-Chip-Codes sind jedoch **zusammengesetzt** — sie haben keine eigene Audiodatei.
Stattdessen teilt das Gerät sie in eine Sequenz vorhandener Dateien auf, um Firmware-Speicher zu sparen.

| NFC chip code | Played as |
| --- | --- |
| `r007` (Repeat 7) | `xrep.mp3` + `n007.mp3` |
| `a001` (+1) | `xplu.mp3` + `n001.mp3` |
| `s005` (−5) | `xmin.mp3` + `n005.mp3` |
| `m002` (×2) | `xmul.mp3` + `n002.mp3` |
| `d003` (÷3) | `xdiv.mp3` + `n003.mp3` |
| `e002` (X²) | `xpow.mp3` + `n002.mp3` |

The full list of physical NFC chip codes and kit contents is in [Befehlschips](/de/nfc).
