## Wie NFC-Codes und Audiodateien zusammenhängen

Jede Audiodatei in der Firmware hat einen Code, der ihrem Dateinamen entspricht. Zum Beispiel gehört zum Code `cfor` die Datei `cfor.mp3`.
Wenn das Steuerboard oder der Roboter einen NFC-Token liest, sucht das Gerät diesen Code und spielt die passende Datei ab.

Einige Token-Codes sind **zusammengesetzt**: Sie haben keine eigene Audiodatei.
Das Gerät setzt sie aus mehreren vorhandenen Dateien zusammen, um Firmware-Speicher zu sparen.

| NFC-Token-Code | Wird abgespielt als |
|---|---|
| `r007` (Wiederholen 7) | `xrep.mp3` + `n007.mp3` |
| `a001` (+1) | `xplu.mp3` + `n001.mp3` |
| `s005` (−5) | `xmin.mp3` + `n005.mp3` |
| `m002` (×2) | `xmul.mp3` + `n002.mp3` |
| `d003` (÷3) | `xdiv.mp3` + `n003.mp3` |
| `e002` (X²) | `xpow.mp3` + `n002.mp3` |

Die vollständige Liste der NFC-Token-Codes und den Inhalt des Sets finden Sie unter [Befehls-Tokens](/de/nfc).
