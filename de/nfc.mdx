## 🧮 Mathematische Operationen

| Operation | NFC-Code |
| --- | --- |
| +1 bis +999 | `a001`–`a999` |
| −1 bis −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Quadratwurzel aus X | `sqrt` |
| Fakultät | `fact` |

Die Arithmetik rechnet im Bereich von −5000 bis 5000. Division und Wurzel werden auf die nächste ganze Zahl gerundet. Gibt es kein Ergebnis (über 5000, Division durch 0, Wurzel aus einer negativen Zahl, Fakultät über 6), blinkt die Zelle rot und die Zahl bleibt unverändert.

## ⚙️ Einstellungen

| Befehl | NFC-Code |
| --- | --- |
| Kalibrierung. Ohne Zahl stellt der Roboter Motoren und Gyroskop ein. Das dauert etwa 2 Minuten. Berühren Sie den Roboter in der ersten halben Minute nicht. Mit dem Token `+N` oder `−N` korrigiert der Roboter die Drehungen nach der Prüfung mit 32 Drehungen. Mit einer einfachen Zahl funktioniert der Token nicht, die Zelle wird rot. | `ccal` |
| Standardschritt. Legt die Schrittlänge für „Vorwärts“ und „Rückwärts“ fest. Auch „Zufällige Bewegung“ verwendet sie (1–999 mm). Ohne Zahl setzt der Token den Schritt auf 150 mm zurück. | `clen` |

## 🔧 Erweitert

| Befehl | NFC-Code |
| --- | --- |
| Klang (siehe [Audio-Datei-Referenz](/de/sounds_reference)) | `xNNN` |
| Roboter-Satz. Legen Sie `csou` und eine Zahl N, dann spricht der Roboter den Satz xN aus den [Audiodateien](/de/sounds_reference#-roboter-sätze-reaktionen-und-servicemeldungen-x001–x019) | `csou` |
| Lautstärke von Steuerboard und Roboter (0–100, eine Zahl über 100 ergibt das Maximum) | `clvl` |

## So schreiben Sie Daten auf einen NFC-Tag

Sie können Ihren eigenen Token erstellen: Schreiben Sie einen Textcode auf einen NFC-Tag. Es passen beliebige Zahlen von 1 bis 999, beliebige Wiederholungen und beliebige Zahlen für arithmetische Operationen.

Installieren Sie dazu die App **RFID NFC Reader** oder **NFC Tools** aus dem Google Play Store auf Ihrem Telefon.

Wie Sie einen NFC-Tag beschreiben, zeigt dieses Video: [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
