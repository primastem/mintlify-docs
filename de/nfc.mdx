## 🧭 Bewegung

| Befehl | NFC Code |
| --- | --- |
| Vorwärts | `cfor` |
| Links | `clef` |
| Rechts | `crig` |
| Rückwärts | `cbac` |
| Zufällige Bewegung | `crnd` |

## 🔁 Wiederholung & Steuerung

| Befehl | NFC Code |
| --- | --- |
| Wiederholen 2–999 | `r002`–`r999` |
| Wiederholen Zufällige Zahl (von 1 bis 6) | `rrnd` |
| Funktion | `cfun` |
| Pause | `cwat` |

## 🔢 Zahlen

| Wert | NFC Code |
| --- | --- |
| Zahlen 1–999 | `n001`–`n999` |

## 🧮 Mathematische Operationen

| Operation | NFC Code |
| --- | --- |
| +1 to +999 | `a001`–`a999` |
| −1 to −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Quadratwurzel aus X | `sqrt` |
| Fakultät | `fact` |

## ⚙️ Einstellungen

| Befehl | NFC Code |
| --- | --- |
| Entfernungskalibrierung | `ccal` |
| Standard-Schrittlänge festlegen | `clen` |

## 🔧 Erweitert

| Befehl | NFC Code |
| --- | --- |
| Audio-Beispiel (siehe [Audiodateien](/de/sounds_reference)) | `xNNN` |
| Pult-Sound-Beispiel | `csou` |
| Lautstärkepegel | `clvl` |

## So schreiben Sie Daten auf einen NFC-Tag

Sie können Ihren eigenen Token erstellen — schreiben Sie einfach einen Textcode auf einen NFC-Tag. Sie können beliebige Zahlen (von 0 bis 999), beliebige Wiederholungen und beliebige Zahlen für arithmetische Operationen verwenden.

Um Textdaten auf einen NFC-Tag zu schreiben, öffnen Sie den Google Play Store und installieren Sie die App **RFID NFC Reader** oder **NFC Tools** auf Ihrem Telefon.

Anleitungen zum Schreiben eines NFC-Tags finden Sie hier — [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
