## 🧮 Mathematische Operationen

| Operation | NFC Code |
| --- | --- |
| +1 to +999 | `a001`–`a999` |
| −1 to −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Quadratwurzel aus X | `sqrt` |
| Fakultät | `fact` |

Die Arithmetik rechnet bis 5000 in beide Richtungen, geteilt wird ohne Nachkommastellen. Gibt es kein Ergebnis (über 5000, Division durch 0, Wurzel aus einer negativen Zahl, Fakultät über 6), blinkt die Zelle rot und die Zahl bleibt unverändert.

## ⚙️ Einstellungen

| Befehl | NFC Code |
| --- | --- |
| Kalibrierung (ohne Zahl: Der Roboter stellt Motoren und Gyroskop ein, etwa 2 Minuten, in der ersten halben Minute nicht berühren; mit Chip `+N` oder `−N`: Korrektur der Drehungen nach der Prüfung mit 16 Drehungen; mit einer einfachen Zahl funktioniert es nicht, die Zelle wird rot) | `ccal` |
| Standard-Schrittlänge festlegen (1–999 mm; ohne Zahl zurück auf 150 mm) | `clen` |

## So schreiben Sie Daten auf einen NFC-Tag

Sie können Ihren eigenen Token erstellen — schreiben Sie einfach einen Textcode auf einen NFC-Tag. Sie können beliebige Zahlen (von 0 bis 999), beliebige Wiederholungen und beliebige Zahlen für arithmetische Operationen verwenden.

Um Textdaten auf einen NFC-Tag zu schreiben, öffnen Sie den Google Play Store und installieren Sie die App **RFID NFC Reader** oder **NFC Tools** auf Ihrem Telefon.

Anleitungen zum Schreiben eines NFC-Tags finden Sie hier — [youtu.be/UbKaQxZs8JA](https://youtu.be/UbKaQxZs8JA)
