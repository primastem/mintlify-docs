## 🧮 Математические операции

| Операция | Код NFC |
| --- | --- |
| От +1 до +999 | `a001`–`a999` |
| От −1 до −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Корень из X | `sqrt` |
| Факториал | `fact` |

Арифметика считает в пределах от −5000 до 5000. Деление и корень округляются до ближайшего целого. Если ответа нет (больше 5000, деление на 0, корень из отрицательного числа, факториал больше 6), ячейка мигнёт красным, а число останется прежним.

## ⚙️ Настройки

| Команда | Код NFC |
| --- | --- |
| Калибровка. Без числа робот настраивает моторы и гироскоп, это занимает около 2 минут. Первые полминуты робота не трогайте. С фишкой `+N` или `−N` робот вносит поправку поворотов после проверки 32 поворотами. С простым числом фишка не работает, ячейка горит красным. | `ccal` |
| Шаг по умолчанию. Задаёт длину шага для «Вперёд» и «Назад», её же берёт «Случайное движение» (1–999 мм). Без числа фишка возвращает 150 мм. | `clen` |

## 🔧 Дополнительно

| Команда | Код NFC |
| --- | --- |
| Звук (см. [Справочник аудиофайлов](/ru/sounds_reference)) | `xNNN` |

| Громкость пульта и робота (0–100, число больше 100 даёт максимум) | `clvl` |

## Как записать данные на NFC-метку

Вы можете сделать свою фишку: запишите текстовый код на NFC-метку. Подходят любые числа от 1 до 999, любые повторы и любые числа для арифметических операций.

Для записи установите на телефон приложение **RFID NFC Reader** или **NFC Tools** из Google Play Store.
