## Как NFC-коды связаны с аудиофайлами

У каждого аудиофайла в прошивке есть код, он совпадает с именем файла. Например, коду `cfor` соответствует файл `cfor.mp3`.
Когда пульт или робот читает NFC-фишку, он ищет этот код и проигрывает нужный файл.

Некоторые коды фишек **составные**: своего аудиофайла у них нет.
Устройство собирает их из нескольких существующих файлов, чтобы сэкономить место в прошивке.

| Код NFC-фишки | Звучит как |
|---|---|
| `r007` (Повтор 7) | `xrep.mp3` + `n007.mp3` |
| `a001` (+1) | `xplu.mp3` + `n001.mp3` |
| `s005` (−5) | `xmin.mp3` + `n005.mp3` |
| `m002` (×2) | `xmul.mp3` + `n002.mp3` |
| `d003` (÷3) | `xdiv.mp3` + `n003.mp3` |
| `e002` (X²) | `xpow.mp3` + `n002.mp3` |

Полный список кодов NFC-фишек и состав набора есть на странице [Фишки-команды](/ru/nfc).
