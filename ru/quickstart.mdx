## 2. Включение

<Steps>
  <Step title="Включите робота, затем пульт" icon="power">
    Каждый проиграет короткий звук; зелёный индикатор питания на каждом устройстве = включено.
  </Step>
  <Step title="Связь есть = белый" icon="check">
    Доступные слоты пульта горят **белым**, глаза робота мигают **белым**. Готово.
  </Step>
  <Step title="Оба синие = нужно связать устройства" icon="bluetooth">
    Удерживайте **▶ Старт** на пульте **>10 секунд** — устройства соединятся, робот перезагрузится.
  </Step>
</Steps>

**Попробуйте сразу:** положите фишку **Вперёд** в первый слот (любую ячейку пары). Нажмите **▶ Старт**. Робот проедет 15 см вперёд и остановится. *Это уже программа — одна команда.*

## 3. Как устроена программа

На пульте **два ряда парных ячеек**. Расставляете фишки в ячейках, которые горят белым — получается программа. Нажимаете **▶ Старт** — робот её выполняет.

<Frame caption="Схема пульта — буквы A–F расшифрованы ниже">
  <img src="../images/book-1/control.excalidraw.svg" alt="Схема пульта с буквенными подписями A-F" />
</Frame>

| Метка | Что это |
| :---: | --- |
| **A** | **Главная программа** — 6 парных слотов, выполняется слева направо |
| **B** | **▶ Старт / Стоп** — запуск; повторное нажатие во время движения = стоп |
| **C** | **Функция** — 5 парных слотов, вызывается фишкой «Функция» |
| **D** | Одна **ячейка** пары |
| **E** | **Линия выполнения**, связывающая ячейки в пару |
| **F** | **Многоцветный LED-индикатор** у каждой ячейки |

**Пара = две логически связанные ячейки.** Порядок верх/низ не важен — команду можно положить в любую ячейку пары, а в соседнюю — повтор, число или арифметику. Если вторая ячейка пары пустая — используется значение по умолчанию: шаг 15 см и поворот 90°, для маленьких детей этого достаточно.

Цвета LED во время выполнения:

| ⚪ Белый | 🟢 Зелёный | 🔵 Синий | 🔴 Красный |
| :---: | :---: | :---: | :---: |
| Ожидание (слот свободен) | Команда стоит | Команда + число / повтор / арифметика | Ошибка — пропускается |

Пустые слоты и красные пары пропускаются. LED моргают на ячейке, исполняющейся прямо сейчас.

## 4. Фишки — по группам

| Группа | Что делают фишки |
| --- | --- |
| **Движение** | Вперёд · Назад · Налево · Направо |
| **Повтор** | Две стрелки по кругу + внутри точки 2–6 (как на игральном кубике, для малышей) или с цифрами. В паре с командой — повторяет её. |
| **Числа** | `1`–`999`. Задают расстояние движения в мм или угол поворота в градусах. |
| **Арифметика** | `+N` `−N` `×N` `÷N` `√` `^N` — одна фишка = операция + число. Модифицирует сохранённое значение движения или поворота. Отрицательный результат меняет направление на обратное! |
| **Функция** | Вызывает нижний ряд как подпрограмму. С фишкой повтора — выполняется заданное число раз. |
| **Шаг** | Служебная фишка + Число = меняет шаг по умолчанию (например число 100, в миллиметрах, для 10-см клетки). Сохраняется после выключения. |

## 5. Значения по умолчанию и сохранённое значение

<Note>
**Вперёд = 150 мм (15 см), поворот = 90°.** Фишка **«Шаг»** меняет расстояние «по умолчанию» и сохраняется после выключения. Используем для игровых карт от любых роботов.

Во время одной сессии каждая команда движения хранит **своё** сохранённое значение:

- **число** в паре к команде → заменяет последнее сохранённое или "по умолчанию"
- **арифметическая** фишка → модифицирует его (`+`, `−`, `×`, `÷`, `√`, `^`)
- **пусто** в паре с командой → берётся последнее сохранённое или "по умолчанию"

Сохранённые значения сбрасываются при выключении пульта, значение по умолчанию (шаг) — остаётся.

**Шпаргалка:**

- `Вперёд` без числа     → 150 мм (15 см) — дефолт
- `Вперёд` + `100`       → 100 мм — заменяет
- `Вперёд` + `+50`       → 150 мм  (прежние 100 + 50) — модифицирует
- `Налево` без числа     → 90° — дефолт
- `Налево` + `45`        → 45° — заменяет
- `Налево` + `−10`       → 35°  (прежние 45° − 10°) — модифицирует
</Note>

## 7. Как учить с помощью PrimaSTEM

<Tip>
**Вводите фишки-команды по одной, в этом порядке:**

**Вперёд → Повороты → Повторы → Функция → Числа → Арифметика.**

Каждую следующую — только после уверенного освоения предыдущей. Полный план 12 занятий с возрастом, длительностью и материалами для маленьких детей — в [Книге 1](book-1/book-1).

**Работа в группе:** рекомендуем один комплект на **2–3 ребёнка**.

**Карты:** подходит любое поле от других учебных роботов. Размер клетки задаётся фишкой **«Шаг»** с числом (например 100, 120, 150, 200 мм).

**Хитрость на 10 шагов вместо 6.** Положите фишку **Функция [ ]** в последний (6-й) слот верхнего ряда и закрепите малярным скотчем. Программа теперь идёт как одна длинная цепочка: 5 верхних шагов + 5 нижних = **10 шагов подряд**. Удобно для малышей, которым нужна программа подлиннее, но рано вводить функцию как концепцию. 
</Tip>

## 8. Дополнительные возможности

<CardGroup cols={2}>
  <Card title="Маркер и рисование" icon="pen-line">
    Вставьте маркер в робота — он **рисует** свой путь на бумаге: от простой траектории до многоугольников, звёзд, спиралей и фракталов.
  </Card>
  <Card title="Голосовая озвучка" icon="volume-2">
    Пульт озвучивает каждую фишку — голос **на любых локальных языках**, сейчас поддерживаем уже **17**, добавим любой по запросу! Помогает маленьким и нечитающим детям. Есть звуки букв алфавита и мест (Дом, Школа, Магазин, Лес и т.д.)
  </Card>
  <Card title="Звуковые NFC метки и карты" icon="map">
    Наклейте NFC-метки на свою карту, запрограммируйте с телефона любой доступный звук. У робота снизу есть антенна — остановившись на метке, он воспроизведёт записанный звук.
  </Card>
  <Card title="Открытая NFC-платформа" icon="nfc">
    Записывайте свои фишки — любая 13.56 МГц NFC-метка (дешёвые, любых видов продаются на всех маркетплейсах) + текст-код из нашей документации — всё вместе занимает 10 секунд. Бесплатное приложение с телефона (NFC Tools).
  </Card>
</CardGroup>
