## Настройка разработки

Узнайте, как обновлять вашу документацию локально и публиковать её публично.

### Редактирование и предпросмотр

<AccordionGroup>
  <Accordion icon="github" title="Клонируйте вашу документацию локально">
    В процессе онбординга мы создали репозиторий на вашем Github с
    содержимым вашей документации. Вы можете найти этот репозиторий на
    [панели управления](https://dashboard.mintlify.com). Чтобы клонировать репозиторий
    локально, следуйте этим
    [инструкциям](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)
    в вашем терминале.
  </Accordion>
  <Accordion icon="rectangle-terminal" title="Предпросмотр изменений">
    Предпросмотр помогает убедиться, что ваши изменения выглядят так, как задумано. Мы создали
    интерфейс командной строки для локального отображения этих изменений.
    1. Установите
    [Mintlify CLI](https://www.npmjs.com/package/mintlify) для локального предпросмотра
    изменений документации с помощью этой команды: ``` npm i -g mintlify ```
    2. Выполните следующую команду в корне вашей документации (там, где
    находится `docs.json`): ``` mintlify dev ```
    <Note>
      Если вы в настоящее время используете устаревший файл конфигурации ```mint.json```, пожалуйста, обновите Mintlify CLI:


      ```npm i -g mintlify@latest```
      И выполните новую команду обновления в репозитории вашей документации:

      ```mintlify upgrade```
      Теперь вы должны использовать новый файл конфигурации ```docs.json```. Не стесняйтесь удалить файл ```mint.json``` из вашего репозитория.
    </Note>
  </Accordion>
</AccordionGroup>

### Развертывание ваших изменений

<AccordionGroup>

<Accordion icon="message-bot" title="Установите наше Github приложение">
  Наше Github приложение автоматически развертывает ваши изменения на сайте документации,
  поэтому вам не нужно управлять развертываниями самостоятельно. Ссылку для установки можно найти на
  вашей [панели управления](https://dashboard.mintlify.com). После успешной установки бота
  рядом с хешем коммита репозитория должна появиться галочка.
</Accordion>
<Accordion icon="rocket" title="Отправьте ваши изменения">
  [Закоммитьте и отправьте ваши изменения в
  Git](https://docs.github.com/en/get-started/using-git/pushing-commits-to-a-remote-repository#about-git-push)
  для обновления вашего сайта документации. Если вы отправили изменения и не видите,
  что Github приложение успешно развернуло ваши изменения, вы также можете вручную
  обновить вашу документацию через нашу [панель управления](https://dashboard.mintlify.com).
</Accordion>

</AccordionGroup>
