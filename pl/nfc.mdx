## 🧮 Działania matematyczne

| Działanie | NFC Code |
| --- | --- |
| +1 do +999 | `a001`–`a999` |
| −1 do −999 | `s001`–`s999` |
| ×N | `m002`–`m999` |
| ÷N | `d002`–`d999` |
| X^N | `e002`–`e999` |
| Pierwiastek kwadratowy z X | `sqrt` |
| Silnia | `fact` |

Arytmetyka liczy do 5000 w obie strony, dzielenie jest bez ułamków. Jeśli wyniku nie ma (ponad 5000, dzielenie przez 0, pierwiastek z liczby ujemnej, silnia ponad 6), pole mignie na czerwono, a liczba pozostanie bez zmian.

## ⚙️ Ustawienia

| Polecenie | NFC Code |
| --- | --- |
| Kalibracja (bez liczby: robot ustawia silniki i żyroskop, około 2 minut, przez pierwsze pół minuty nie dotykaj go; z żetonem `+N` lub `−N`: poprawka obrotów po sprawdzeniu 16 obrotami; ze zwykłą liczbą nie działa, pole robi się czerwone) | `ccal` |
| Ustaw domyślną długość kroku dla mapy (1–999 mm; bez liczby wraca do 150 mm) | `clen` |

## 🔧 Zaawansowane

| Polecenie | NFC Code |
| --- | --- |
| Próbka audio (zobacz [Spis plików audio](/pl/sounds_reference)) | `xNNN` |
| Dźwięk (robot odtwarza dźwięk o numerze N: `csou` + liczba N) | `csou` |
| Poziom głośności (pilot i robot: 0–100, powyżej 100 = maksimum) | `clvl` |

## Jak zapisać dane na tagu NFC

Możesz zrobić własny żeton: wystarczy zapisać kod tekstowy na tagu NFC. Możesz użyć dowolnych liczb (od 0 do 999), dowolnych powtórzeń i dowolnych liczb w działaniach arytmetycznych.

Aby zapisać dane tekstowe na tagu NFC, otwórz Sklep Google Play i zainstaluj na telefonie aplikację **RFID NFC Reader** lub **NFC Tools**.
