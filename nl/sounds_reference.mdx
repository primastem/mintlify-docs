## Hoe NFC-codes en audiobestanden samenhangen

Elk audiobestand in de firmware heeft een code die overeenkomt met de bestandsnaam. Bij de code `cfor` hoort bijvoorbeeld het bestand `cfor.mp3`.
Wanneer de bediening of de robot een NFC-kaartje leest, zoekt die deze code op en speelt het juiste bestand af.

Sommige codes van kaartjes zijn **samengesteld**: ze hebben geen eigen audiobestand.
Het apparaat bouwt ze op uit meerdere bestaande bestanden om firmwareruimte te besparen.

| Code van het NFC-kaartje | Afgespeeld als |
|---|---|
| `r007` (Herhaal 7) | `xrep.mp3` + `n007.mp3` |
| `a001` (+1) | `xplu.mp3` + `n001.mp3` |
| `s005` (−5) | `xmin.mp3` + `n005.mp3` |
| `m002` (×2) | `xmul.mp3` + `n002.mp3` |
| `d003` (÷3) | `xdiv.mp3` + `n003.mp3` |
| `e002` (X²) | `xpow.mp3` + `n002.mp3` |

De volledige lijst met codes van NFC-kaartjes en de inhoud van de set staat in [Commandokaartjes](/nl/nfc).
